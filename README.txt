משחקי הגיבורים - חבילה לפריסה ב-Git / GitHub Pages
====================================================

החבילה מוכנה לפריסה ישירה (כוללת .nojekyll, index.html, css/style.css, js/ ו-images/story/).

מה להשלים לפני העלאה סופית ל-Git:
1. תיקיית family/: העתק לכאן את קובצי המדיה של המשפחה (shai.mp4, emma.mp4, ariel.mp4, tia.mp4, ari.mp4, ilan.mp4, itay.mp4 וכו').
2. תמונות זיכרון ופאזל: העתק את תיקיות images/memory/ והתמונות ב-images/ אם ברצונך להשתמש בתמונות המותאמות שלך.
3. תמונת סיום משותפת לכל החיות (אופציונלי): ניתן להחליף/להוסיף תמונה משותפת של הכלב, הקיפוד והפינגווין ב-images/story/ ולעדכן ב-js/config.js.
